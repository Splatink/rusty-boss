# Header typeface

`RussoOne-Regular.ttf` is an **unmodified** copy of Russo One by Jovanny Lemonad.
Copyright (c) 2011–2012, Jovanny Lemonad (jovanny.ru).
Reserved Font Name: "Russo".

License: SIL Open Font License 1.1. The complete copyright notice and license are
in `OFL-RussoOne.txt`, also embedded in the binary and readable under
Settings → Help & connection log → Typeface license. Keep the license with
redistributed font files. This font was not taken from BOSS Tone Studio.

Upstream: https://github.com/google/fonts/tree/14f3bd097a44db854285fae061ae0fe6eb1a583b/ofl/russoone

Font SHA-256: `bc0abcc660bd8b7ad3000ecb2898a27c58a29a50f7ec81652fa12e75148d09df`

The font is bundled at build time—there is no runtime download or dependency on
installed system fonts. It is registered as a dedicated egui font family, not a
replacement for the body/UI font. Glyphs are rasterized through the normal text
pipeline at the current pixels-per-point; the app never enlarges a cached logo
bitmap or manually scales a glyph mesh.
